# 12 — Decisions and open questions

## Accepted for blueprint

- Create a clean-room spiritual successor, not a remake.
- Preserve static image/text/commands and async community.
- Use a responsive web client for phone and PC.
- Use Cloudflare Workers + D1 for a free-first prototype.
- Use deterministic server-authoritative rules and economy ledger.
- Build one semantic UI with retro and modern visual modes.
- Delay cards, guilds, trade, PvP, ads, and supporter commerce behind gates.
- All named characters are 20+; optional non-explicit suggestive presentation is off by default.
- No paid gacha or paid combat power.

## Owner decisions needed before vertical slice content lock

1. Public language: Japanese only first, or localization-ready Japanese/English?
2. Player avatar: fixed protagonist, selectable body, or abstract profile portrait?
3. Death/defeat penalty: durability/time/currency, or only route reset?
4. Energy/stamina: recommended **none**; confirm.
5. How close should retro mode feel: feature-phone narrow column vs early desktop portal?
6. Art production path: commissioned, local generative pipeline, mixed, or placeholders first?
7. World tone: darker urban relic fantasy vs brighter adventure comedy?
8. Initial social identity: display names only vs generated handles until account link?
9. Initial repository visibility and collaborator list.
10. Working codename replacement timeline.

## Decisions needed before public alpha

- target countries and account age policy;
- final name/trademark/domain clearance;
- privacy/analytics approach;
- content rating and platform distribution plan;
- support/moderation staffing expectations;
- hard monthly cloud budget and alert recipient;
- whether optional suggestive presentation ships at all;
- whether source code will remain private, become source-available, or open source.

## Explicit default when unanswered

Choose the lowest-risk reversible option: Japanese-first but localization-ready, no stamina, no item-loss death penalty, general-audience art only, no trade/PvP/monetization, private repository, and one small region.
