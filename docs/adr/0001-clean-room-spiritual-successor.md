# ADR 0001 — Clean-room spiritual successor

- Status: Accepted
- Date: 2026-08-19

## Context
The owner wants to revive the feel of a discontinued game while respecting it. Direct reproduction creates copyright, trademark, confusion, and maintainability risk.

## Decision
Build an original-IP spiritual successor. Historical research may produce abstract principles only. Production uses original names, lore, art, copy, layouts, formulas, data, and code.

## Consequences
We can preserve static command play, asynchronous world presence, collection, and community without claiming continuity. Direct source assets/data and “official revival” marketing are prohibited. Public launch requires name/IP review.
