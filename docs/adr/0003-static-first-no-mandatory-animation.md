# ADR 0003 — Static-first, no mandatory animation

- Status: Accepted
- Date: 2026-08-19

## Decision
Still images, text, and semantic commands are the primary medium. No animation, video, Live2D, audio, or real-time 3D is required to play or understand any system. Brief reduced-motion-safe feedback is allowed.

## Consequences
Art scope, bandwidth, and accessibility improve; spectacle must come from composition, writing, rarity, and logs. Any animation proposal must be optional and demonstrate no regression to core usability.
