# Contributing

Project Neverlight is private during blueprint and prototype development.

## Before opening a PR

- Select exactly one backlog packet.
- Read `AGENTS.md` and the packet’s Skills.
- Create an issue or reference an existing issue.
- Keep protected references out of commits, issues, screenshots, and fixtures.
- Include verification evidence and cost/security/accessibility notes.

## Branch and commit convention

- Branch: `agent/<issue>-<short-description>`
- Commit examples:
  - `chore: bootstrap pnpm workspace`
  - `feat(combat): resolve seeded turn commands`
  - `docs: record market escrow decision`
- Prefer conventional commits, one concern per commit when practical.

## Pull requests

Use `.github/pull_request_template.md`. Draft by default. Never self-enable trade, PvP, ads, supporter commerce, or explicit content.
